## Getting Started

### Prerequisites
- GCC compiler (MinGW for Windows, gcc for Linux/Mac)
- Any text editor or IDE (VS Code, Code::Blocks, Dev-C++)

### Installation
1. Clone the repository:
```bash
git clone https://github.com/ShubhagamanSingh/C_programming.git
```
2. Navigate to the desired directory:
```bash
cd C_programming/basics
```
## Compilation Instructions

### 1. Basic Compilation
```bash
gcc program_name.c -o output_name
./output_name
```
### 2. With Debugging Information
```bash
gcc -g program_name.c -o output_name
```
### 3. With Warnings Enabled
```bash
gcc -Wall program_name.c -o output_name
```
### 4. Using Make (for projects)
```bash
make
./executable_name
```
